HUMAN-LIKE COGNITIVE ARCHITECTURE

Perceive → Orient → Recall → Forecast → Challenge → Synthesize → Risk → Execute → Learn.

“Human-like” in AURA means explicit cognitive functions and adversarial review, not consciousness. Specialist agents generate structured evidence, Bull/Bear/Counterfactual views challenge it, and the deterministic CEO synthesizes before independent financial risk gets final authority.
